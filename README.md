# AI Usage Widget

Claude · ChatGPT · Gemini 구독 플랜의 사용량을 작은 always-on-top 위젯 하나로 확인합니다.

![screenshot](docs/screenshot.png)

## 표시되는 항목

| 서비스 | 표시 지표 |
|---|---|
| Claude | 5시간(현재 세션) 한도, 주간 한도 |
| ChatGPT | 주간 사용량 한도 |
| Gemini | 현재 사용량, 주간 한도 |

각 항목마다 사용률(%)과 초기화 시각을 함께 보여주고, 5분마다 자동으로 갱신합니다.

## 주요 기능

- **항상 위 고정** — 다른 창 위에 계속 떠 있음 (📌 버튼으로 토글)
- **호버 타이틀바** — 평소엔 숨어 있고 상단에 마우스를 올리면 나타남
- **배경 투명도 조절** — 타이틀바의 슬라이더로 조절
- **트레이 상주** — 작업표시줄에 나타나지 않고 트레이 아이콘만 표시

## 설치

[Releases](../../releases) 에서 최신 `AI-Usage-Widget-Setup-x.x.x.exe` 를 받아 실행하세요. (Windows x64)

> 서명되지 않은 설치 파일이라 Windows SmartScreen 경고가 뜰 수 있습니다.
> "추가 정보" → "실행"으로 진행할 수 있습니다.

## 최초 실행

처음 실행하면 세 서비스 모두 로그인이 필요합니다. 각 줄 오른쪽의 ↗ 버튼으로 해당
서비스를 열어 로그인하세요. 로그인 세션은 앱 안에 저장되어 다음 실행에도 유지됩니다.

앱은 사용자의 비밀번호를 저장하거나 다루지 않습니다. 로그인은 각 서비스의 공식
로그인 화면에서 직접 이루어집니다.

## ⚠️ 사용 전 반드시 읽어주세요

이 앱은 각 서비스의 **공개 API가 아니라, 로그인된 웹 화면을 열어 사용량 텍스트를
읽는 방식**으로 동작합니다. 이로 인한 제약과 위험이 있습니다.

- **약관 위반 소지** — 서비스에 따라 자동화된 접근을 약관에서 제한할 수 있습니다.
  이 앱의 사용으로 발생하는 계정 제재 등 모든 책임은 사용자 본인에게 있습니다.
- **UI 변경 시 동작 중단** — 각 서비스가 화면 구조나 문구를 바꾸면 사용량을 읽지
  못하고 "오류"로 표시될 수 있습니다.
- **지원 언어** — 서비스 UI 언어가 **한국어 또는 영어**일 때 동작합니다. 다른
  언어로 설정되어 있으면 값을 읽지 못합니다.
- **표시 값은 참고용** — 항상 각 서비스의 공식 화면이 정확합니다.

## 개인정보

- 사용량 확인은 전적으로 사용자의 PC 안에서만 이루어집니다. 어떤 데이터도 외부
  서버로 전송하지 않습니다.
- 로그인 세션은 Electron의 표준 세션 저장소에 서비스별로 분리 저장됩니다.
- 진단용 페이지 덤프는 **기본적으로 저장하지 않습니다.** 문제 신고를 위해 필요한
  경우에만 `AI_USAGE_DEBUG=1` 환경변수로 실행할 때 저장되며, 이 덤프에는 대화
  제목과 계정 이메일이 포함될 수 있으므로 공유 전에 반드시 내용을 확인하세요.

## 직접 빌드하기

```bash
npm install
node scripts/make-icons.js
npm start        # 개발 실행
npm run dist     # Windows 설치 파일 생성
```

빌드 결과물은 `%TEMP%/aiuw-build/` 에 생성됩니다. 프로젝트 폴더 안이 아닌 임시 폴더로
빌드하는 이유는, 일부 안티랜섬웨어(예: AppCheck)가 압축 과정에서 폴더에 미끼 파일을
심어 7-Zip 압축을 실패시키기 때문입니다.

파싱 로직 테스트:

```bash
node scripts/test-parse.js
```
